这个需求本身没什么问题——你想让AI生成的小说文字更自然、更有人情味，这是正当的写作辅助需求。我来给你一些实用的提示词建议。

## 去除AI味的核心提示词策略

### 1. 文风人性化指令

```
你是一位有10年经验的网文作者，擅长写[玄幻/都市/穿越]类型小说。
请用以下风格创作，避免AI常见问题：

【禁止使用】
- 禁止使用排比句堆砌（如"他感到愤怒、悲伤、迷茫"）
- 禁止使用"宛如""仿佛""犹如"等过度比喻
- 禁止段落结构过于工整对称
- 禁止使用"不禁""顿时""瞬间"等网文滥词
- 禁止每段都以人名开头
- 禁止使用总结性陈述句结尾

【要求使用】
- 口语化、不完整的句子
- 人物的内心独白要有语气词（"妈的、这也太离谱了吧、嗯？"）
- 描写要有细节不均匀感（有时啰嗦有时跳跃）
- 偶尔用错别字或网络用语（符合人物身份）
```

### 2. 节奏打乱指令

```
写作时请注意：
- 句子长短要不规律，短句和长句交替，不能每句都差不多长
- 段落长度要参差不齐：有时一句话一段，有时五六句一段
- 对话后不要每次都加动作描写，有时就是干对话
- 允许出现不完整的意识流描写
- 重要情节可以"拖戏"，无聊的过场用一句话带过
```

### 3. 人物口吻差异化

```
请为以下角色设定专属语言习惯：
- 主角：爱用反问句，说话简短，偶尔带脏字（用*代替）
- 反派：说话文绉绉但偶尔露出市井气
- 配角A：口头禅是"...吧？"，经常说半句话

对话中要保持角色语言特征，不能让所有人说话风格一样。
```

### 4. 情绪表达去模板化

```
描写人物情绪时：
- 不要直接说"他很愤怒"，要通过行为细节体现
- 情绪描写要不对称：愤怒可以表现为"忽然很想笑"
- 避免情绪升级过于线性（不是：平静→微怒→大怒）
- 可以用身体反应代替心理描写（手指发麻、喉咙发干）
```

### 5. 叙述视角混乱感（模仿人类写作习惯）

```
允许叙述中出现：
- 轻微的视角漂移（第三人称中偶尔插入"读者可能不知道的是..."）
- 作者吐槽式的插叙（"当然，他当时不知道这个决定有多蠢"）
- 非必要的闲笔（路边的猫、无关的天气）
- 伏笔可以不收（像真实作者一样偶尔忘了）
```

### 6. Claude Code 整改建议

你可以让 Claude Code 在你的生成系统中加一个**后处理层**：

```
# 后处理提示词（对生成结果二次润色）

你是专业的网文编辑，请对以下AI生成文本进行人性化处理：

1. 找出所有结构对称的句子，打乱其中一句
2. 找出3处以上的"宛如/仿佛/犹如"，至少删除2处
3. 将过长的段落（超过8行）拆分，加入一个无关紧要的细节
4. 检查对话，确保不同角色说话风格有差异
5. 在文章开头或结尾加入一处"作者视角"的碎碎念
6. 随机选择1-2处顺畅的叙述，改得稍微啰嗦或跳跃一点

输出修改后的文本，不要解释修改原因。
```

------

这些提示词的核心思路是：**模仿人类写作的"缺陷"和"不规律性"**，而不是追求AI擅长的整齐、完整、对称。你把这些组合进生成流程，效果会明显改善。
