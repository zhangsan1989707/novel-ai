## 一、功能层面优化建议

### 1.1 高优先级功能

#### 1.1.1 章节生成进度可视化
**问题**: 当前章节生成缺乏实时进度反馈，用户无法了解 AI 处理状态。

**建议方案**:
```typescript
// 增强流式响应，添加进度标识
interface ChapterGenerationProgress {
  phase: 'planning' | 'writing' | 'polishing' | 'validating' | 'finalizing'
  progress: number // 0-100
  currentStep: string
  estimatedTimeRemaining?: number
}
```

**实现要点**:
- SSE 事件添加 `progress` 事件类型
- 前端显示多阶段进度条（策划→写作→润色→校验→保存）
- 显示预估剩余时间

#### 1.1.2 批量生成支持
**问题**: 当前只能逐章生成，长篇小说创作效率低。

**建议方案**:
- 支持队列式批量生成（最多 10 章/批次）
- 断点续传机制
- 并发控制（防止 API 限流）

```typescript
interface BatchGenerationRequest {
  startChapter: number
  endChapter: number
  priority: 'high' | 'normal' | 'low'
  maxConcurrent: number // 默认 3
}
```

#### 1.1.3 AI 模型对比功能
**问题**: 用户无法直观比较不同模型的输出质量。

**建议方案**:
- 同一章节使用多个模型并行生成
- 并排展示对比结果
- 用户可选择最佳结果或手动合并

### 1.2 中优先级功能

#### 1.2.1 写作风格引导面板
**现状**: "去 AI 味" 提示词分散在不同文件中。

**建议方案**:
- 新增「写作风格」配置面板
- 可视化调整各项风格参数
- 保存预设风格模板

#### 1.2.2 角色自动追踪
**问题**: 角色关系和状态需要手动维护。

**建议方案**:
- 基于生成内容自动提取角色出场
- 自动更新角色关系图
- 冲突检测（角色行为前后矛盾）

#### 1.2.3 章节评分系统
**问题**: 用户无法量化章节质量。

**建议方案**:
- 基于多维度评分（节奏、冲突、文笔、一致性）
- 历史章节质量趋势图
- 改进建议自动生成

### 1.3 低优先级功能

#### 1.3.1 协作功能
- 多用户同时编辑同一项目
- 评论和批注系统
- 版本分支管理

#### 1.3.2 社区功能
- 写作模板分享
- 热门设定库
- 虚拟作家市场

### 2.1 架构优化

**现状**: `prompts.ts` 文件超过 800 行，包含多个不同用途的提示词。

#### 2.1.3 AI Provider 中间件
**现状**: 6 个 Provider 实现有大量重复代码。

**建议方案**:
```typescript
// 中间件类型
type AIMiddleware = (
  request: AIRequest,
  next: () => Promise<AIResponse>
) => Promise<AIResponse>

// 内置中间件
const middlewares: AIMiddleware[] = [
  rateLimitMiddleware,      // 限流
  retryMiddleware,           // 重试
  cacheMiddleware,          // 缓存
  costTrackingMiddleware,   // 成本追踪
  loggingMiddleware,        // 日志
]

// 应用中间件
async function withMiddleware(request: AIRequest): Promise<AIResponse> {
  let index = 0
  const next = async (): Promise<AIResponse> => {
    if (index >= middlewares.length) {
      return sendToProvider(request)
    }
    const middleware = middlewares[index++]
    return middleware(request, next)
  }
  return next()
}
```

### 2.2 性能优化

#### 2.2.1 数据库查询优化
**问题**: 批量操作存在 N+1 查询问题。

**现状代码**:
```typescript
// 糟糕：N+1 查询
for (const chapter of chapters) {
  const project = await prisma.novelProject.findUnique(...)
}
```

**优化后**:
```typescript
// 使用 include 和事务
const result = await prisma.$transaction(async (tx) => {
  const projectIds = chapters.map(c => c.projectId)
  const projects = await tx.novelProject.findMany({
    where: { id: { in: projectIds } }
  })
  const projectMap = new Map(projects.map(p => [p.id, p]))
  
  return chapters.map(chapter => ({
    ...chapter,
    project: projectMap.get(chapter.projectId)
  }))
})
```

**建议**:
- AI 模型配置缓存（TTL: 5 分钟）
- 项目摘要缓存（按章节号版本）
- 用户配额缓存（TTL: 1 分钟）

```typescript
// 使用 LRU 缓存
const configCache = new LRUCache<string, AIModelConfig>({
  max: 100,
  ttl: 5 * 60 * 1000, // 5 分钟
```

```typescript
class AppError extends Error {

    super(message)
```

```typescript
// src/middleware/response.ts
export function responseHandler(
  handler: (req: Request, res: Response) => Promise<any>
) {
  return async (req: Request, res: Response) => {
    try {
      const data = await handler(req, res)
      res.json({ success: true, data })
    } catch (error) {
      if (error instanceof AppError) {
        res.status(error.statusCode).json({
          success: false,
          error: {
            code: error.code,
            message: error.message,
            details: error.details
          }
        })
      } else {
        logger.error({ error }, 'Unhandled error')
        res.status(500).json({
          success: false,
          error: { code: 'INTERNAL_ERROR', message: '服务器内部错误' }
        })
      }
    }
  }
}
```

### A.2 Agent 执行包装器

```typescript
// src/lib/agents/executor.ts
export async function withAgentLogging<T>(
  agentType: AgentType,
  projectId: number,
  chapterNo: number,
  fn: () => Promise<T>
): Promise<T> {
  const log = await prisma.agentLog.create({
    data: {
      projectId,
      chapterNo,
      agentType,
      status: 'START'
    }
  })

  const startTime = Date.now()
  
  try {
    const result = await fn()
    
    await prisma.agentLog.update({
      where: { id: log.id },
      data: {
        status: 'DONE',
        durationMs: Date.now() - startTime
      }
    })
    
    return result
  } catch (error) {
    await prisma.agentLog.update({
      where: { id: log.id },
      data: {
        status: 'FAILED',
        errorMessage: error instanceof Error ? error.message : String(error),
        durationMs: Date.now() - startTime
      }
    })
    throw error
  }
}
```
