# AI 网文平台最终改造清单（实施版）

当前项目基础：

- 多 Agent 流水线
- 分层摘要系统
- StoryState
- Plotline 伏笔系统
- Context Compression
- 去 AI 味
- 长文本上下文管理
- 多模型调度
- 成本追踪

这些基础已经足够。

项目下一阶段目标：

# 从：

```text
AI 写作工具
```

# 升级为：

# 「AI 长篇网文工业化生产系统」

核心方向：

- AI 全自动控制
- 用户仅做高层方向调整
- AI 控制整本书节奏与扩张
- 支持无限续写
- 防止长篇崩坏
- 防止提前结局
- 解决上下文限制与超时问题

------

# 一、产品定位重构

# 当前错误方向

当前产品偏：

```text
Word + AI
```

存在：

- 重编辑器
- 重参数配置
- 重人工参与

这是错误方向。

------

# 正确方向

# 「AI 网文导演系统」

用户：

```text
给灵感
```

AI：

```text
自动生产整本书
```

------

# 二、用户输入系统重构（极重要）

# 原则

用户只输入：

# “用户真正懂的东西”

不要让用户碰：

- 卷结构
- 章节结构
- 节奏控制
- 爽点算法
- 世界阶段
- 伏笔生命周期
- 反派生命周期

这些全部 AI 自动控制。

# 七、目录系统重构（核心）

# 当前问题

AI 把：

```text
生成 N 章
```

理解为：

```text
完整故事
```

导致：

- 提前大结局
- 提前终局
- 世界写死

------

# 正确方向

# 目录 = 阶段目录

不是全书目录。

------

# 八、目录层级结构

新增：

```text
Book Blueprint
↓
Arc Plan
↓
Chapter Batch Outline
```

------

# 1. Book Blueprint

只定义：

- 核心卖点
- 世界方向
- 主线方向
- 成长方向
- 终局可能性

不生成完整章节。

------

# 2. Arc Plan

定义当前阶段：

```text
开局
成长
扩张
中期冲突
大战前夕
终局
```

------

# 3. Chapter Batch Outline

只生成：

```text
当前批次章节
```

例如：

- 10章
- 20章
- 30章
- 一个副本
- 一个阶段

AI 自动决定。

------

↓
AI 生成 Arc Plan
↓

Validator

Polisher

Deslopper

更新 StoryState

更新 Plotline

```

# 二十、超时与上下文限制（重点）

```

------

GenerationJob {

  status

  retryCount
  payload
  result

# 二十一、Checkpoint 系统（必须）

新增：

```ts
PipelineCheckpoint
```

保存：

- 输入
- 输出
- 当前步骤
- 错误
- 状态

模型超时后：

# 从 checkpoint 恢复。

不要整批失败。

------

# 二十二、正文生成规则（极重要）

# 正文必须逐章生成

不要：

```text
一次生成20章正文
```

------

# 正确：

```text
生成第N章
↓
生成摘要
↓
更新 StoryState
↓
更新 Plotline
↓
生成第N+1章
```

------

# 二十三、上下文系统重构

新增：

```ts
ContextBudgetManager
```

------

# 上下文结构

```ts
ChapterContext {
  bookBlueprint
  currentArcPlan
  currentOutline
  recentChapterSummaries
  relevantCharacters
  activePlotlines
  worldRules
  styleGuide
}
```

------

# 上下文预算

```ts
{
  blueprint: 10%
  arcPlan: 15%
  summaries: 25%
  plotlines: 15%
  characters: 15%
  styleGuide: 10%
  currentOutline: 10%
}
```

------

# 超限裁剪规则

优先丢弃：

- 老正文
- 过期角色
- 已关闭伏笔
- 旧阶段目标

保留：

- 当前目标
- 活跃伏笔
- 主角状态
- 世界规则

------

# 二十四、模型降级策略

新增：

```ts
ModelFallbackPolicy
```

------

# 规则

```text
超时
↓
重试
↓
降级模型
↓
仍失败则暂停任务
```
